# Ibiza 2026

Landing page du séjour à Ibiza du 18 au 21 septembre 2026.

## Développement local

```bash
npm install
npm run dev
```

## Déploiement Netlify

Le dépôt contient déjà la configuration nécessaire :

- commande de build : `npm run build`
- dossier de publication : `dist`
- version de Node.js : `22`

Dans Netlify, importez simplement ce dépôt GitHub et lancez le déploiement. Aucun secret ni variable d’environnement n’est requis.
